# Асимптотика решений ЛР1

Рябихин Виталий, группа 31.

n, m — размеры массивов. Доп. память — память сверх входных данных и массива с ответом.

| Задача | Время | Доп. память |
|---|---|---|
| 1. Максимум и минимум | O(n) | O(1) |
| 7. Второй максимум | O(n) | O(1) |
| 11. Ближайший к среднему | O(n) | O(1) |
| 19. Слияние отсортированных массивов | O(n + m) | O(1) |
| 20. Сортировка подсчётом | O(n + k), k = max − min + 1 | O(k) |
| 34. Максимальная сумма подмассива | O(n) | O(1) |
| 35. Префиксные суммы | O(n) предподсчёт, O(1) запрос | O(n) |
| 38. Циклический сдвиг влево | O(n) | O(1) |
| 45. Разбиение по опорному | O(n) | O(1) |

## Задача 1
Один проход по массиву, на каждом элементе два сравнения — O(n). Храним только min и max — O(1).

## Задача 7
Один проход, на каждом элементе максимум два сравнения — O(n). Храним два числа — O(1).

## Задача 11
Первый проход считает сумму, второй ищет ближайший элемент: 2n = O(n). Память — несколько переменных, O(1).

## Задача 19
За каждый шаг цикла в ответ записывается ровно один элемент, всего n + m шагов — O(n + m). Кроме массива ответа храним три индекса — O(1).

## Задача 20
Поиск min и max — O(n), заполнение счётчиков — O(n), выписывание ответа — O(k + n); k = max - min + 1. Итого O(n + k). Массив счётчиков длины k — O(k). Если k намного больше n, сортировка становится невыгодной, поэтому диапазон ограничен 10⁷.

## Задача 34
Один проход, на каждом шаге два Math.max — O(n). Память — две переменные, O(1).

## Задача 35
Подсчёт префиксных сумм — один проход, O(n), массив из n + 1 элемента — O(n). Каждый запрос — одно вычитание, O(1). На q запросов — O(n + q) вместо O(n · q) при наивном подсчёте.

## Задача 38
Три разворота: k/2 + (n − k)/2 + n/2 = n обменов — O(n). Обмены на месте, одна временная переменная — O(1).

## Задача 45
На каждом шаге либо i растёт, либо greater уменьшается, поэтому шагов ровно n — O(n). Обмены на месте — O(1).
