## Идеи решений

Везде используются обычные массивы: доступ по индексу за O(1), никаких лишних объектов.

- **1. Максимум и минимум.** Один проход, храним текущие min и max.
- **7. Второй максимум.** Один проход, храним два самых больших числа. Если пришло число больше первого, старый первый становится вторым.
- **11. Ближайший к среднему.** Среднее бывает дробным, а дроби в double сравниваются неточно. Поэтому сравниваю |a[i] · n − сумма| — это то же расстояние, умноженное на n, но в целых числах (long).
- **19. Слияние.** Два указателя: каждый раз берём меньший из двух текущих элементов, потом дописываем остаток.
- **20. Сортировка подсчётом.** Считаем, сколько раз встречается каждое число, и выписываем их по порядку. Индекс счётчика = число − min, чтобы работали отрицательные числа. min и max ищутся методом из задачи 1.
- **34. Алгоритм Кадане.** Для каждой позиции храним лучшую сумму подмассива, который на ней заканчивается: либо продолжаем старый подмассив, либо начинаем новый.
- **35. Префиксные суммы.** prefix[i] — сумма первых i элементов. Сумма на отрезке [l, r] = prefix[r + 1] − prefix[l].
- **38. Сдвиг влево.** Массив = A B, нужно B A. Разворачиваем A, разворачиваем B, разворачиваем всё. k берём по модулю n.
- **45. Разбиение.** Три указателя (задача о голландском флаге): меньшие уходят влево, большие вправо, равные остаются в середине.

## Асимптотика

Подробно — в [complexity.md](complexity.md). Все требования из условия выполнены: 19 — O(n + m), 34 — O(n), 35 — O(1) на запрос, 38 и 45 — O(n) и O(1) памяти.

## Ручные тесты

| Задача | Ввод | Ответ | Зачем |
|---|---|---|---|
| 1 | `2` / `2147483647 -2147483648` | `-2147483648 2147483647` | границы int |
| 7 | `4` / `1 2 3 4` | `3` | максимум меняется каждый шаг, старый должен уйти во второй |
| 11 | `2` / `3 2` | `3` | два элемента одинаково близки — берём первый |
| 19 | `2` / `5 6` / `3` / `1 2 3` | `1 2 3 5 6` | один массив кончается сразу, нужно дописать остаток другого |
| 20 | `6` / `3 -2 5 3 0 -2` | `-2 -2 0 3 3 5` | отрицательные числа и повторы |
| 34 | `3` / `-3 -1 -2` | `-1` | все числа отрицательные, ответ не 0 |
| 35 | `3` / `7 -3 9` / `1` / `1 1` | `-3` | отрезок из одного элемента |
| 38 | `4` / `1 2 3 4` / `5` | `2 3 4 1` | k больше n |
| 45 | `4` / `8 1 6 2` / `5` | `2 1 6 8` | опорного числа нет в массиве |

Эти же случаи есть в автоматических тестах в папке `src/test`.
